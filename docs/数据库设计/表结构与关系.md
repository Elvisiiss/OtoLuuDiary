# 数据库设计说明

## 基本信息

- **数据库名**: `otoluudiary`
- **字符集**: `utf8mb4`
- **引擎**: `InnoDB`
- **连接**: `jdbc:mysql://110.42.193.119:31101/otoluudiary`

## 表清单

| 表名 | 说明 | 关联 |
|------|------|------|
| `user` | 用户表 | — |
| `diary` | 日记表 | `diary.user_id` → `user.id` |
| `diary_media` | 日记媒体文件表 | `diary_media.diary_id` → `diary.id` |

## 表关系

```
user (1) ──── (N) diary (1) ──── (N) diary_media
     一个用户有多篇日记          一篇日记可有多个媒体文件
```

> 未设物理外键约束，由应用层保证数据一致性。

## 字段命名规范

| 规范 | 示例 |
|------|------|
| 字段名全小写，单词间下划线分隔 | `diary_date`、`created_at` |
| 主键统一用 `id`，UUID 格式 VARCHAR(36) | `a1b2c3d4-...` |
| 时间统一用 BIGINT 毫秒时间戳 | `1725993600000` |
| JSON 字段用 MySQL JSON 类型 | `tags` 列 |

## 特殊逻辑

### diary_date（日记日期）

`diary_date` 是日记的"归属日期"，与创建时间 `created_at` 解耦。

**默认规则（凌晨4:00分界线）**：

```
当前时间 < 04:00 → diary_date = 昨天 00:00:00
当前时间 ≥ 04:00 → diary_date = 今天 00:00:00
```

- 前端优先计算并发送
- 后端兜底计算（使用服务器本地时区）
- 存储为当天 00:00:00 的毫秒时间戳
- 用户可在创建/编辑时手动选择日期
- 列表按 `COALESCE(diary_date, created_at)` 排序

### importance（重要度）

0-5 的整数，0 表示未设置，1 最低，5 最高。前端用星级选择器展示。

### content（富文本内容）

存储 HTML 格式的富文本（由 Quill 编辑器生成）。支持：
- 文字颜色（用户可选颜色）
- 文字大小（标题/正文/小字等）
- 图片、视频嵌入

### 媒体文件存储

- 文件保存在服务器 `uploads/` 目录
- 通过 `/api/uploads/**` 静态资源路径访问
- `diary_media` 表记录文件元数据

## 旧数据兼容

已有的无新字段的日记记录，前端会使用默认值显示。
