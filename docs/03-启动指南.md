# 启动指南（Windows PowerShell）

> 最后更新：2026-08-25

请严格按照以下步骤操作。**必须先启动后端，再启动前端**，否则前端页面会提示「无法连接后端服务」。

---

## ⚠️ 第一步：确认依赖软件已安装

打开 PowerShell，分别运行下面三条命令，确认都能正常显示版本号：

```powershell
java -version     # 需要 17 或以上
mvn -v            # 需要 3.8+
node -v           # 需要 18 LTS 或以上
```

如果有任何一条提示「找不到命令」，请先回到 [02-全局环境说明.md](./02-全局环境说明.md) 按说明安装并配置环境变量。

---

## ☕ 第二步：启动后端（Spring Boot）

打开**一个新的 PowerShell 窗口**，执行：

```powershell
# 1. 进入后端目录
cd e:\Project\OtoLuuDiary\backend

# 2. 编译并启动后端（第一次运行会下载依赖，需要几分钟，请耐心等待）
mvn spring-boot:run
```

启动成功后，你会在窗口里看到类似下面的文字：

```
============================================
  OtoLuuDiary 后端启动成功！
  服务地址: http://localhost:8080/api
============================================
```

✅ **验证后端是否可用**（可以在浏览器里打开这个地址测试）：

- 查看全部日记：<http://localhost:8080/api/diaries>  （第一次会返回 `{"success":true,"message":"操作成功","data":[]}`）
- 查看全部标签：<http://localhost:8080/api/tags>

后端启动后，**这个 PowerShell 窗口不要关闭**（否则后端就停止了）。

---

## 💻 第三步：启动前端（Electron 桌面端）

打开**另一个新的 PowerShell 窗口**（注意：后端的窗口别关），执行：

```powershell
# 1. 进入前端目录
cd e:\Project\OtoLuuDiary\frontend

# 2. 安装前端依赖（只需要第一次运行，之后启动就不用再跑这行了，耗时几分钟）
npm install

# 3. 启动桌面应用
npm start
```

启动成功后，会弹出一个标题为「欧托留日记」的桌面窗口。

🎉 **恭喜！现在你可以开始写日记了！**

---

## 📁 数据存在哪里？

所有日记都保存在：

```
e:\Project\OtoLuuDiary\data\diaries.txt
```

格式说明：每行一条 JSON。如果你要备份数据，直接复制这个文件即可。

后续要切换 MySQL 时，`DiaryRepository` 这个类里的读写逻辑都可以直接替换成 MySQL 版，其他代码不用改。

---

## ❓ 常见问题

### Q1：启动前端后页面提示「无法连接后端服务」
A：确认后端窗口还开着，而且后端启动日志里显示了「后端启动成功」。如果后端没启动，请先执行第二步。

### Q2：mvn spring-boot:run 报错「找不到符号」或「编译失败」
A：请检查 JDK 版本是否是 17+，再执行一次 `mvn clean compile` 看看具体哪行报错。

### Q3：npm install 很慢
A：可以切换成国内淘宝镜像再试：
```powershell
npm config set registry https://registry.npmmirror.com
# 然后再 npm install
```

### Q4：如何停止程序？
A：前端直接关闭窗口即可。后端在 PowerShell 窗口里按 `Ctrl + C` 停止。
