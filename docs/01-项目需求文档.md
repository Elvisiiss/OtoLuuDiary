# OtoLuuDiary（欧托留日记）项目需求文档

> 最后更新：2026-08-25

---

## 一、项目概述

### 1.1 项目名称
- 中文名：欧托留日记
- 英文名：OtoLuuDiary

### 1.2 项目简介
一款跨平台日记软件，用户可以随时随地记录自己的生活。

### 1.3 目标平台（按开发优先级）
1. ✅ **Windows 编译端**（当前阶段优先开发）
2. ⏳ 网页端
3. ⏳ Linux 编译端
4. ⏳ 手机端（安卓/iOS）

> 说明：由于无法实现一套代码所有平台通用，故采用分阶段开发策略。
> 第一阶段专注于把 Windows 端做好做稳。

---

## 二、技术选型（第一阶段：Windows 端）

| 层级 | 技术 | 选型理由 |
|------|------|----------|
| **桌面端前端** | Electron | 使用 HTML/CSS/JS 开发桌面应用，后续迁移到网页端最方便，一套代码两用 |
| **后端框架** | Java + Spring Boot | 生态成熟、资料丰富、入门简单，适合后续扩展和连接 MySQL |
| **前后端通信** | REST API | 简单通用，前后端对接方便 |
| **数据存储** | TXT 文本文件 | 第一阶段先用 TXT 存数据，降低复杂度；后续会接入 MySQL 数据库 |
| **项目结构** | Monorepo（前后端同一仓库） | 方便管理，前后端代码放在同一个项目文件夹内 |

---

## 三、功能需求（第一阶段 MVP）

### 3.1 日记数据结构（一条日记包含的内容）

| 字段名 | 类型 | 说明 | 是否必填 |
|--------|------|------|----------|
| id | String（UUID） | 日记唯一编号 | 系统自动生成 |
| title | String | 日记标题 | ✅ 必填 |
| content | String（纯文本） | 日记正文内容 | ✅ 必填 |
| tags | List\<String\> | 标签列表，如 ["工作","旅游"] | 可选 |
| weather | String | 记录当天天气，如 "晴"、"雨" | 可选 |
| mood | String | 记录心情，如 "开心"、"平静" | 可选 |
| createdAt | Long（时间戳） | 创建时间 | 系统自动生成 |
| updatedAt | Long（时间戳） | 最后修改时间 | 系统自动更新 |

### 3.2 核心功能清单

| 编号 | 功能 | 说明 | 优先级 |
|------|------|------|--------|
| F01 | 🆕 新增日记 | 填写标题、正文，可选填标签/天气/心情，保存后生成一条新日记 | 高 |
| F02 | 📄 查看日记列表 | 显示所有日记的列表（按时间倒序，最新的在前），每条显示标题+时间+标签 | 高 |
| F03 | 🔍 查看日记详情 | 点击列表中某条日记，查看完整内容 | 高 |
| F04 | ✏️ 编辑日记 | 修改已有日记的任意字段，保存后更新修改时间 | 高 |
| F05 | 🗑️ 删除日记 | 删除一条不需要的日记（确认后删除） | 高 |
| F06 | 🔎 关键词搜索 | 在搜索框输入关键词，按标题或正文搜索匹配的日记 | 中 |
| F07 | 🏷️ 标签筛选 | 按标签筛选日记，点击某个标签只显示该标签下的日记 | 中 |

### 3.3 暂缓功能（后续版本迭代）
以下功能留到以后版本再做，第一阶段不实现：
- 📅 日历视图（在日历上查看哪天写了日记）
- 📤 导出功能（导出为 TXT / PDF）
- 🔐 用户登录 / 多用户系统
- 🔒 日记加密（密码锁）
- 🎨 富文本编辑（加粗、图片、颜色等）

---

## 四、用户特性
- 本软件为**单用户设计**（第一阶段），不需要注册登录，打开即可使用
- 数据保存在本地，不上传云端
- 目标用户：普通大众，操作尽量简单直观

---

## 五、非功能需求
- **性能**：打开软件 3 秒内看到主界面
- **可用性**：界面简洁，新手无需教程即可上手
- **可扩展性**：后端代码预留 MySQL 接入能力，方便后续切换数据库
