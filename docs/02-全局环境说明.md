# 全局环境说明文档

> 最后更新：2026-08-25

---

## 一、开发者机器环境

| 项目 | 说明 |
|------|------|
| **操作系统** | Windows（本项目开发机为 Windows 环境） |
| **Shell** | PowerShell 7+（或 Windows 自带 PowerShell） |
| **工作目录** | `e:\Project\OtoLuuDiary` |

---

## 二、软件依赖（需要提前安装）

### 2.1 后端依赖（Java 后端）

| 软件 | 版本要求 | 作用 | 安装验证命令（Windows PowerShell） |
|------|----------|------|-------------------------------------|
| **JDK** | 17 或以上 | Java 开发工具包，运行 Spring Boot | `java -version` |
| **Maven** | 3.8+ | Java 项目构建工具，管理依赖 | `mvn -v` |

> 说明：如果 JDK 和 Maven 尚未安装，请先下载安装：
> - JDK 17 下载：https://adoptium.net/ （选 Temurin JDK 17 LTS）
> - Maven 下载：https://maven.apache.org/download.cgi
> - 安装后记得配置环境变量 `JAVA_HOME` 和 `MAVEN_HOME`，并把 `bin` 目录加到 `PATH`

### 2.2 前端依赖（Electron 前端）

| 软件 | 版本要求 | 作用 | 安装验证命令（Windows PowerShell） |
|------|----------|------|-------------------------------------|
| **Node.js** | 18 LTS 或以上 | JavaScript 运行时 | `node -v` |
| **npm** | 随 Node.js 自带 | Node 包管理器 | `npm -v` |

> 说明：Node.js 下载地址：https://nodejs.org/ （选 LTS 长期支持版）

## 三、常用命令速查表（Windows PowerShell）

### 后端相关（Java Spring Boot）
```powershell
# 进入后端目录
cd e:\Project\OtoLuuDiary\backend

# 编译项目
mvn clean compile

# 启动后端服务（开发模式）
mvn spring-boot:run
```

### 前端相关（Electron）
```powershell
# 进入前端目录
cd e:\Project\OtoLuuDiary\frontend

# 第一次使用时安装依赖（只需跑一次）
npm install

# 启动前端桌面应用（开发模式）
npm start
```
